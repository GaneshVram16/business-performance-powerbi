# Business Performance Dashboard — Power BI

A Power BI portfolio build pack built around a star-schema sales model.

## What is included
- Reproducible synthetic-data generator
- Fact and dimension model design
- DAX measures
- KPI definitions
- Power BI Project (`.pbip`) scaffold
- Preview charts and validated summary outputs
- Step-by-step dashboard build instructions

## Dataset
Synthetic business-performance dataset:
- 18,000 fact rows
- 2 calendar years (2024–2025)
- Product, region and channel dimensions
- Revenue, cost, profit, discount, quantity and delivery-SLA fields

## Validated headline KPIs
- Revenue: **₹81,523,731**
- Profit: **₹26,039,724**
- Profit margin: **31.9%**
- SLA compliance: **72.6%**
